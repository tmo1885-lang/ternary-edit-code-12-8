# A 12-word ternary edit code (length 12, minimum distance 8)

**Theresa Rainaldi — Velorin Intelligence — 16 November 2026**

We exhibit 12 distinct ternary words of length 12 whose minimum pairwise unit-cost Levenshtein distance is 8. Thus **E₃(12,8) ≥ 12**, improving the previously listed lower bound of 11. This is a constructive lower bound, **not** an exact determination of E₃(12,8).

The code is generated by cyclic shifts of four generators:
```text
000002222211
000111111222
002120201010
022222002222
```

Run `python verify_edit_code.py` (Python 3, standard library only) to verify the exact canonical certificate hash and all 66 pairwise distances.

Pairwise distances: 57 pairs at 8, and 3 pairs each at 9, 10 and 11.

Independent verification and public attribution: https://abrahamyeung.com/edit-codes/#r3-12-8
